# App Icon Generation

This directory contains scripts for generating app icons for Pistisai across different platforms.

## Prerequisites

> **Verified against code (2026-11-24):** there is no `scripts/generate_icons.ps1` and no logo image under `assets/images/` in this repo. Icons are generated from `assets/images/app_icon.png` via `flutter_launcher_icons.yaml` (`dart run flutter_launcher_icons:main`), and `scripts/convert_icons_to_ico.py` produces the Windows `.ico`. Windows assets live in lowercase `windows/runner/resources/` (not `Resources/`).

> Historical prerequisites (for the removed legacy script): install ImageMagick from https://imagemagick.org/script/download.php and provide a logo image under `assets/images/` (for example `Pistisai_logo.jpg`).

## Generating Icons

To generate all app icons, run from the project root:

```bash
dart run flutter_launcher_icons:main
```

This generates icons for the platforms enabled in `flutter_launcher_icons.yaml`:

- Web (`web/icons/`, generated by the `web.generate: true` entry)
- Android (`min_sdk_android: 21`)

> **Verified against code (2026-11-24):** `flutter_launcher_icons.yaml` sets `ios: false` and there is no `ios/` directory in this repo, so the older iOS icon list has been removed. Windows `.ico` files are produced separately by `scripts/convert_icons_to_ico.py`.

## Icon Locations

- Windows icons: `windows/runner/resources/` (lowercase; `Resources/` does not exist; generated by `scripts/convert_icons_to_ico.py`)
- Android icons: `android/app/src/main/res/mipmap-*/`
- Web icons: `web/icons/` (per `flutter_launcher_icons.yaml`)
- iOS icons: not generated (`ios: false` in `flutter_launcher_icons.yaml`; no `ios/` directory)

## Troubleshooting

If you encounter any issues:

1. Make sure `assets/images/app_icon.png` exists (the source used by `flutter_launcher_icons.yaml`)
2. Run `flutter pub get` so `flutter_launcher_icons` is available
3. Check that you have write permissions in the target directories
